# NOVA TERRA

Website ficticio premium e minimalista para projeto academico de marketing.

## Como abrir

1. Abre esta pasta no Visual Studio Code.
2. Abre o ficheiro `index.html`.
3. Para ver no browser, usa uma destas opcoes:
   - Clica duas vezes em `index.html` no Explorador do Windows.
   - Ou instala a extensao **Live Server** no VS Code e escolhe **Open with Live Server**.

## Onde editar

- `index.html`: estrutura das secoes e textos principais.
- `styles.css`: cores, layout, espacamentos, responsividade e animacoes.
- `script.js`: listas reutilizaveis para historia, servicos, ofertas, shop e merchandising.

## Identidade visual

- Preto: `#000000`
- Branco: `#FFFFFF`
- Terracota: `#E35336`
- Tipografia: Nunito
